# Real-Time Crowd Density Estimation

Estimates crowd density from images or video streams using a CSRNet model 
converted to OpenVINO IR format via `ov.convert_model()`.

## Source

This app is hosted at: https://github.com/arunimakanavu/crowd-density

## Details

- **Model:** CSRNet (OpenVINO IR)
- **Related AI concepts:** crowd counting, density estimation
- **Platforms:** Client (CPU, GPU), Edge (CPU)
